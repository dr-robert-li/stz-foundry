## 0. What v3.1 is

v3 with ONE change: the scoring contract accepts a second fence dialect.
Everything else — warehouse generator, six-step pipeline, task prompts, arms,
graded scoring, leak checks, independent interpreter — is byte-identical to
v3. The grid probe measured 3%→60% of baseline-arm tasks (G1→G5) emitting
answers in a plain ```` ```json ```` fence instead of the required
```` ```path=answer.json ```` fence, content-driven rather than
length-driven, making every hard point's difficulty uninterpretable. v3.1
removes that nuisance from the PRIMARY endpoint and keeps it visible as a
SECONDARY one.

## 1. The one mitigation — exact parsing semantics (two-implementer-proof)

A task built by `buildTasksV3_1` declares the fence alias. Parsing rules, in
order, fail-closed (panel: kimi §5, gpt-sol-pro §5):

1. Collect fenced blocks whose info string contains `path=answer.json`
   (existing contract, unchanged). If ≥1 exists, the FIRST is the artifact;
   the alias is never consulted. Explicit always wins.
2. Otherwise collect fenced blocks whose info string, lowercased and
   trimmed, is EXACTLY `json`. If EXACTLY ONE exists, its body is the
   artifact `answer.json`. Zero, or more than one → no artifact (ambiguity
   fails closed; the task instruction says exactly one block).
3. An artifact whose body is not valid JSON observes to nothing on every
   check (existing `observeCheck` behaviour) — it counts as NO ARTIFACT for
   the drop-rate budget (kimi 2: the budget counts unusable responses, and
   an unparseable body is unusable).
4. **Strict-contract endpoint (secondary):** every task also records whether
   rule 1 alone would have produced its artifact. Reported per arm and per
   point; NEVER an acceptance input; preserved because exact
   downstream-contract adherence is a real capability the relaxation
   deliberately stops measuring in the primary.

Per the one-shot rule this is the ONLY mitigation: no prompt text changes, no
grammar beyond this alias, no second dialect later.

## 3. Instrumentation

Every probe task stores in checkpoint state: raw response text verbatim;
relaxed (primary) graded score + exact flag; strict-contract flag; status;
input/output tokens; wall-clock. Zeros decompose prospectively into
correct-and-strict / correct-but-aliased / parseable-but-wrong /
no-artifact. No future phase of this arm runs without raw-text retention.

**Run configuration recorded as part of the instrument** (kimi 1b): ollama
version, model digest, modelfile sampler parameters, `OLLAMA_NUM_PARALLEL`,
client concurrency (1), task order (battery order, sequential). Tasks are
never re-drawn: a task that dies to a HARNESS fault (`error` status —
connection refused, server restart, kill) is retried exactly once, and the
retry is logged in state; a `timeout` at the 3600s bound is a measurement
and is never retried. Same seed + same knobs regenerate the identical
warehouse (deterministic generator, test-enforced).

## 4. The pre-registered grid and probe

**Points:** G1, G2, G3, G4 (the v3 knob table, unchanged).

**G5 exclusion — a pre-registered SCOPE choice, honestly grounded** (kimi 2
caught rev 1's false arithmetic and the claim is withdrawn: the all-drops-
correct bound on G5's relaxed baseline is 0.001 + 0.60 ≈ 0.60, which is NOT
below the corridor). G5 is excluded because: (i) its 44k-token prompts are
the furthest outside the v2 comparability envelope (~34× v2, vs G1's ~7×) —
the length confound the decision panel flagged is maximal there; (ii) its
strict floor collapsed to 0.036 with BOTH arms dead, so even optimistic
relaxation leaves the floor clause marginal; (iii) ~20h of inference. This
is scope, not necessity, and is fixed here before any data.

**Probe seeds:** 7, 42, 1234 (Phase A continuity) + 11, 101, 2027 (fresh) =
6 seeds × 10 tasks = n=60 per arm per point.

**The CI estimator, pinned** (gpt-sol-pro §2, kimi 1a — the rev 1 gap):
the unit of replication is the SEED. For each arm × point: compute the six
per-seed mean graded scores; the corridor test uses the t-distribution 90%
CI on those six means (t₅,₀.₉₅ = 2.015): mean ± 2.015 · sd/√6. Per-task
pooling understates seed-level draw dependence (measured ±0.13 in Phase A);
seed-clustered t is the conservative, correct choice. Power, recomputed
under THIS estimator from Phase A seed-level variance: G1-like sd 0.12 →
expected width ≈ 0.20; G2-like sd 0.14 → ≈ 0.23. The corridor test is
therefore demanding at 6 seeds — a point qualifies only if its seed spread
is genuinely small. That is intended: a point whose seeds disagree by ±0.14
is not a stable instrument, and widening n to force qualification would
reintroduce the lottery this rule exists to kill. No coverage target beyond
the estimator itself is pre-registered; the estimator IS the rule.

**Arms:** s2-strong, s0-minimal (`_v3-arms.ts`, unchanged; the mitigation is
arm-symmetric by construction — it is scoring, not prompting).

**Stage-1 acceptance rule (ALL clauses, primary endpoint):**
1. Baseline seed-clustered 90% CI (estimator above) ⊆ [0.30, 0.60].
2. s0-minimal pooled mean ≥ 0.05.
3. Baseline pooled mean(graded) − pooled exact-rate ≥ 0.10, where
   `exact` = the task's every check passed (the existing binary metric).
4. Relaxed no-artifact rate ≤ 0.10 on EACH arm separately, evaluated PER
   POINT over that point's 60 tasks (gpt-sol-pro §2: a fence-dominated floor
   arm could otherwise manufacture separation; qwen-max 2: never pooled
   across points).
5. Arm order: baseline pooled mean > s0 pooled mean, AND sign(baseline
   seed-mean − s0 seed-mean) > 0 on ≥ 5 of 6 seeds. A zero difference
   counts as a violation (sign(0) is not positive).

**Format-stability gate (runs FIRST), with its failure branch pre-committed**
(gpt-sol-pro C3, kimi 1c): ceiling probe (answer given) at all four points ×
seeds 7, 42, dual scoring, n=20 per point. A point PASSES the gate iff its
relaxed no-artifact count = 0 AND its mean relaxed graded score ≥ 0.95
(denominator: all 20 tasks). A point failing the gate is EXCLUDED from the
difficulty probe. If ALL four points fail, the content-driven premise is
falsified and the arm TERMINATES (§6) — this is kimi's §7 addition, adopted.

**Noise and selection, de-biased** (gpt-sol-pro C2 — rev 1's smallest-noise
selection preferentially picked downward noise errors and then reused them
anti-conservatively in the headroom test):
- SELECTION among stage-1 qualifiers is by the predeclared priority
  G1 > G2 > G3 > G4 (fewest levers first), independent of measured noise.
- The selected point then runs THREE baseline replicate pairs on the seed-7
  promotion half (6 runs, scored through the relaxed PRIMARY endpoint like
  everything else; the first of each pair may be the stage-1 unit where
  cached). Noise = the MAXIMUM |pair difference| across the three pairs
  (conservative). Headroom requires (1 − baseline pooled mean) ≥
  3 × that maximum. Headroom failure ⇒ the next point in priority order
  enters stage 2, once; exhaustion ⇒ termination.

**Stage 2 — confirmation on fresh seeds 13, 77, 3001** (gpt-sol-pro C1:
rev 1's "same rule" was impossible at 3 seeds; stage 2 is CONFIRMATION, not
re-estimation, with its own explicit rule): both arms, n=30/arm. The
selected point is confirmed iff (i) baseline pooled mean ∈ [0.30, 0.60]
(point estimate — a 3-seed CI-containment test would be the
winner's-curse lottery gpt-sol-pro §2 names); (ii) sign(baseline − s0)
seed-mean difference > 0 on ALL 3 seeds; (iii) relaxed no-artifact ≤ 0.10
on each arm. Failure ⇒ next stage-1 qualifier in the predeclared priority
order (kimi §3) enters stage 2, once each; exhaustion ⇒ termination. No
re-runs, no seed swaps, ever.

A point passing gate + stage 1 + noise/headroom + stage 2 is the candidate
for human acceptance.

## 5. Strict-endpoint disclosure (quantified; kimi §4, gpt-sol-pro §4)

At the candidate point, compute per arm: gap = relaxed mean − strict-scored
mean. If |gap(s2-strong) − gap(s0-minimal)| > 0.15, the point carries a
MANDATORY disclosure in the acceptance briefing and in every downstream
report: prompt-driven fence discipline differs materially between arms and
the relaxation is absorbing a real capability difference. This is
informational BY PRE-REGISTRATION — it never auto-disqualifies and never
enters the acceptance arithmetic — but it cannot be omitted or summarized
away. (Pre-declaring it informational is what removes the post-data
discretion kimi §4 objected to.)

## 6. One-shot termination — scope pinned (gpt-sol-pro §3, kimi §3)

If no point passes the gate, stage 1, headroom and stage 2, the v3
instrument line TERMINATES, and the prohibition is on SUBSTANCE, not name:
no successor instrument that tests this hypothesis — prompt-search vs
hand-written baseline on the data-ops fact-recovery task family, as the
phase-5 promotion gate — may be built under ANY label (v3.2, v4, "new
arm", "new pilot") by changing parser, prompts, grid, scoring, or
qualification rules. Any change to the parsing seam after termination is a
prohibited new generation of this line. What remains legitimate after
termination: publishing the three-generation terminal report (v1 saturated;
v2 saturated, Goodharting eliminated; v3/v3.1 unable to place difficulty in
the corridor without format confounds); using this run's diagnostics to
design instruments for DIFFERENT hypotheses or task families; and phase 5
staying gated, with docs/ROADMAP.md item 8 saying exactly that.
Stage-2 attempts follow the predeclared priority order only; the terminal
condition is exhaustion of that order.

## 8. Pre-committed falsifiers (extended per panel)

- Format-stability gate failing ALL points ⇒ the content-driven premise is
  false ⇒ terminal finding (kimi).
- Relaxed scoring failing to bring any of G2–G4's drop rates under 0.10 ⇒
  drops were never mostly dialect drift ⇒ the one-shot rule ends the arm.
- Arm inversion persisting at a point under relaxed scoring ⇒ that point is
  unsound (stage-1 clause 5) and the phenomenon is reported as a finding
  about methodology prompts under load.
- G1 qualifying while its gradient stays < 0.10 is impossible by
  construction (clause 3) — if G1 is the only corridor-shaped point and
  fails clause 3, that is a gradient-design failure and terminates the arm
  like any other exhaustion.
- §5's disclosure threshold triggering at the candidate point ⇒ disclosed,
  never hidden, acceptance still human.
- Every stage-1 qualifier failing stage 2 (qwen-max: named for completeness)
  ⇒ exhaustion of the priority order ⇒ termination, same as no qualifier at
  all. Stage-2 failure across the board on points that all looked corridor-
  shaped at stage 1 is itself reportable evidence of seed-level instability.
