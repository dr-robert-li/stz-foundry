## 2. Altitude separation and carried-forward META-RSI conclusions

Agent-definition prompt-search altitude — where this milestone operates — is a distinct object
from harness-genome RSI, which is `experiments/META-RSI-SURVEY.md`'s ground. The distinction that
matters mechanically: agent-definition altitude optimizes the **text an LLM agent is given**
(its prompt, instructions, or skill definition) while the harness, the orchestration code, the
model weights, and the meta-loop that wires the agent together stay fixed. Harness-genome
altitude optimizes the harness/orchestration/weight layer itself, including loops that rewrite
their own harness or co-evolve harness and weights. Several papers surfaced in this sweep sit
squarely at that second altitude (`### D`-prefixed "Harness" self-evolution titles throughout §4)
and are excluded on that basis, exactly as META-RSI's own corpus was — this survey does not
re-cover that ground.

**Carried unchanged:** the post-4.8 harness-RSI literature corroborates rather than rescues STZ's
earned negative (`experiments/META-RSI-SURVEY.md` Part I §7); α_t > 0 exogenous correctness
grounding is the one earned direction identified there and remains unproven for continuity; and
the calibrated-verifier sufficiency gate (`experiments/META-RSI-SURVEY.md` Part II §II.6, "target-task
*calibration* is the sufficiency gate") stands as stated. These conclusions are **not re-litigated
here** — nothing in §3 below revises them, because §3 stays inside agent-definition altitude and
never touches the harness-genome question META-RSI already answered.

## 3. Survey entries

### E-01 — Two-Stage Prompt Optimization for Few-Shot Relation Extraction

- **Primary source:** https://arxiv.org/abs/2606.29639
- **v1 submitted:** 2026-06-28
- **Fetch-verified:** https://arxiv.org/abs/2606.29639 retrieved 2026-08-09; title and v1 date match
- **Verdict:** validated
- **Bar applied:** The gain (GradPO local refinement improving prompts found by a first-stage reasoning-based optimizer, reported as state-of-the-art on FS-TACRED) is measured on the standard few-shot benchmark's query split, distinct from the support examples the gradient/loss signal is computed over — a standard train/eval separation for this benchmark family, not the optimized signal itself.

Combines a reasoning-guided prompt-search first stage with a gradient-guided refinement second
stage (GradPO), which uses loss and gradient signals to identify high-impact prompt spans and
apply local edits. Spans both the prompt-space-search and textual-gradient families at
agent-definition altitude: the object being optimized throughout is the prompt text handed to a
smaller LLM doing few-shot relation extraction, never a harness or model weights.

### E-02 — Contrastive Reflection for Iterative Prompt Optimization

- **Primary source:** https://arxiv.org/abs/2606.30840
- **v1 submitted:** 2026-06-29
- **Fetch-verified:** https://arxiv.org/abs/2606.30840 retrieved 2026-08-09; title and v1 date match
- **Verdict:** validated
- **Bar applied:** The paper explicitly separates the validation set that gates edit acceptance from the reported "held-out exact-match accuracy" (51.4% to 60.4% on HotPotQA), and shows failure-only and random-evidence ablations improve less — evidence the gain traces to the contrastive-reflection mechanism rather than to measuring on the same signal that drove acceptance.

An iterative prompt-optimization loop for agentic IR workflows: error-anchored behavioral slices
from QA/grading-agent traces are paired with nearby successful examples, a Teacher LLM proposes a
targeted edit, and the edit is accepted only if held-out validation improves (optionally
regression-checked). GEPA-style reflective evolution at agent-definition altitude — the object
evolved is the prompt controlling the QA and grading agents.

### E-03 — From Failing to Passing: Evolving Natural Language Prompt Optimization Rules for LLM Code Generation

- **Primary source:** https://arxiv.org/abs/2607.05121
- **v1 submitted:** 2026-07-06
- **Fetch-verified:** https://arxiv.org/abs/2607.05121 retrieved 2026-08-09; title and v1 date match
- **Verdict:** validated
- **Bar applied:** The strongest evidence against circularity is the transfer claim: rules evolved on one model transfer zero-shot to other models "without any re-optimization" and still outperform execution-feedback repair — a gain that survives being measured on a model the evolutionary loop never touched cannot be explained by the loop's own optimization signal.

A search-based approach evolves a reusable set of natural-language prompt-transformation rules
(error-agnostic, prompt-space search at agent-definition altitude) and combines them with
execution-feedback repair (DUALFIX) to fix coding failures LiveCodeBench/APPS baselines miss.

### E-04 — Efficient Test-Time Optimization for Multi-Agent Proof Autoformalization (ToMap)

- **Primary source:** https://arxiv.org/abs/2607.11307
- **v1 submitted:** 2026-07-13
- **Fetch-verified:** https://arxiv.org/abs/2607.11307 retrieved 2026-08-09; title and v1 date match
- **Verdict:** unvalidated
- **Bar applied:** The refinement loop's own optimization signal is "formal verification progress together with semantic proof rubrics" defining a Pareto frontier, and the reported +19.0% gain is measured on "syntactic correctness and semantic faithfulness" — the identical two axes the search optimizes against. This is the circular-positive shape META-RSI's bar downgrades: no independent held-out oracle separates the training signal from the reported metric.

A GEPA-inspired reflective-evolution loop applied to the Decomposer stage of a
Decomposer-Formalizer-Prover multi-agent pipeline for proof autoformalization: prompts over
candidate proof decompositions are evolved and selected by the same verification/rubric signal
used to report the final gain.

### E-05 — BayesPO: Bayesian Prompt Optimization via Parallel-Tempered Gradient-Guided Discrete MCMC

- **Primary source:** https://arxiv.org/abs/2607.16001
- **v1 submitted:** 2026-07-17
- **Fetch-verified:** https://arxiv.org/abs/2607.16001 retrieved 2026-08-09; title and v1 date match
- **Verdict:** unvalidated
- **Bar applied:** The posterior driving the MCMC search is defined by "a task likelihood term, which rewards prompts that explain input-output examples" — and the authors themselves disclose that "energy minimization may overfit small optimization sets," i.e. the same input-output examples the reported accuracy gain is checked against. Self-disclosed overfitting risk to the optimized signal is exactly the circularity concern META-RSI's bar exists to catch, so the claimed gain is downgraded rather than taken at face value.

Reframes prompt optimization as Bayesian posterior sampling over discrete prompt tokens
(prompt-space search at agent-definition altitude), using gradient-guided MCMC with parallel
tempering to escape local optima; demonstrated as a post-optimization step on top of APE prompts.

### E-06 — From Agent Failures to Text Policies: What Works and What Breaks

- **Primary source:** https://arxiv.org/abs/2607.20668
- **v1 submitted:** 2026-07-22
- **Fetch-verified:** https://arxiv.org/abs/2607.20668 retrieved 2026-08-09; title and v1 date match
- **Verdict:** unvalidated
- **Bar applied:** Task success on TextWorldExpress is an independent, non-circular held-out signal (it is not the trajectory-derived feedback the policy-learning step consumes), so this is not a scored-down circular positive — it is a direct negative result: "policies generated from agent trajectories do not reliably outperform fixed prompting, even with richer traces, counterfactual evidence, or iterative GEPA search."

Studies applying TextGrad-style textual-gradient feedback at agent altitude, where feedback
arrives only after a sequence of actions. Separates the ability to *follow* a useful text policy
from the ability to *learn* one from experience, and finds a clear gap: hand-written policies help
(+5.0 success points on two frozen 7B agents), but policies the method itself learns from
experience — including via iterative GEPA search — do not reliably beat fixed prompting. Directly
on-point for REQ-39's altitude question and included precisely because it is a documented failure
mode, not a manufactured positive.

### E-07 — GRADRAG: Cross-Component Prompt Adaptation for Coordinated Multi-Agent RAG

- **Primary source:** https://arxiv.org/abs/2607.21324
- **v1 submitted:** 2026-07-23
- **Fetch-verified:** https://arxiv.org/abs/2607.21324 retrieved 2026-08-09; title and v1 date match
- **Verdict:** unvalidated
- **Bar applied:** The Evaluator that "critiques downstream answers and supporting evidence" to produce the feedback signal driving prompt updates, and the final reported metric ("LLM-judged pairwise comparisons," a 12-15 point net preference margin), are both LLM-judge mechanisms of the same family — the paper does not establish that the reported preference margin is independent of the judgment signal the optimization loop itself consumes, so the gain is downgraded rather than counted as validated.

Models a multi-agent RAG pipeline as a computational graph and propagates structured evaluator
feedback upstream to update retriever, graph-constructor, and answerer prompts — textual-gradient
methods (feedback propagation as an update signal) at agent-definition altitude.

### E-08 — Self-Supervised Skill Optimization (SSO)

- **Primary source:** https://arxiv.org/abs/2607.28777
- **v1 submitted:** 2026-07-30
- **Fetch-verified:** https://arxiv.org/abs/2607.28777 retrieved 2026-08-09; title and v1 date match
- **Verdict:** validated
- **Bar applied:** SSO's own optimization signal is deliberately unlabeled (an LLM judge comparing behaviors on an unlabeled batch, with acceptance gated on an unlabeled validation set), while the reported result — approaching or exceeding the strongest ground-truth-based skill optimizer on closed-ended benchmarks — is scored against those benchmarks' ground-truth labels, a signal the optimization loop never sees. The separation is a structural property of the method, not an incidental split.

Learns a reusable agent skill (frozen-agent procedural guidance, a prompt-like artifact) from
unlabeled task instances alone: runs the current skill, generates skill probes, has an LLM judge
compare outcomes, and accepts an update only if it beats the current skill on an unlabeled
validation set. Prompt-space search at agent-definition altitude.

### E-09 — FLARE: Few-shot Learning-based Adaptive Reflective Engine

- **Primary source:** https://arxiv.org/abs/2608.02919
- **v1 submitted:** 2026-08-03
- **Fetch-verified:** https://arxiv.org/abs/2608.02919 retrieved 2026-08-09; title and v1 date match
- **Verdict:** validated
- **Bar applied:** Reported gains (up to +14.2 points on HotPotQA, GoEmotions micro-F1 on the "full 5408-example test split") are measured on standard supervised test splits distinct from the up-to-100-example validation set the paper states the method needs to reach peak performance — a disclosed, non-trivial train/val/test separation, not the optimized signal reported back as the result.

Directly challenges GEPA's reflective-instruction-evolution framing by combining reflective
mechanisms with a small few-shot reference set, reporting wins over GEPA on every task-model pair
tested (retrieval-augmented reasoning, tool calling, multi-label emotion classification). GEPA-style
reflective evolution at agent-definition altitude, evaluated directly against the family's seed
method.
